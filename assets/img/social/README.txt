YOUR PROFILE PICTURE FOR EACH SOCIAL NETWORK
============================================

Save your profile photo for each network in THIS folder, using
exactly these filenames:

    instagram.jpg
    facebook.jpg
    linkedin.jpg

(.png is fine too - if you use .png, update the "avatar" filename
 in assets/js/gallery-posts.js to match.)

HOW TO GET EACH PICTURE
-----------------------
Open your profile in a browser, right-click your profile photo and
choose "Save image as...". Or take a screenshot and crop it square.

TIPS
----
- Square images look best. Anything else is centre-cropped to a circle.
- ~400x400 pixels is plenty. Resize big files at squoosh.app first.
- If a file is missing, that card falls back to your main site
  portrait automatically - it will never show a broken image.
